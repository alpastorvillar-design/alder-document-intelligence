{# The copilot: a drawer, not a panel in the page. It was an inline box under the findings, which meant a reviewer had to scroll away from what they were reading to ask about it, and the answer arrived somewhere else again. A drawer sits beside the work: the evidence stays on screen while the question is asked about it, and it closes when it is in the way. Everything the drawer offers comes from `GET /dossiers/{id}/questions`, so the screen never claims a model the process cannot reach. The suggested questions are the exception - they are built from this dossier's own descuadres and findings, server-side, because a blank box is the hardest thing to start with. Include it in a page that defines `dossier`, and pass `copilot_prompts`. #}
